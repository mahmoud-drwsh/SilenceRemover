pipeline
├── phase_0_trim_script_generation
│   ├── skip_conditions
│   │   └── trim script already generated
│   │       ├── checked_path_templates
│   │       │   └── temp_dir/trim_scripts/{script_key}.ffscript
│   │       └── checked_runtime_templates
│   │           ├── is_trim_script_ready(...) -> script file exists and load_trim_script(...) succeeds
│   │           └── load_trim_script(...) requires a non-empty filter graph body; strategy is inferred later from the graph plus current input/target context
│   └── robustness
│       └── reasonable; readiness is file-based, invalidates on input identity plus trim-affecting params encoded in the script path, and requires one valid self-contained trim graph artifact
├── phase_1_snippet_creation
│   ├── skip_conditions
│   │   ├── snippet already exists and is non-empty
│   │   │   ├── checked_path_templates
│   │   │   │   └── temp_dir/snippet/{basename}.ogg
│   │   │   └── checked_runtime_templates
│   │   │       └── is_snippet_done(temp_dir, basename) -> path exists and stat().st_size > 0
│   │   └── trim script missing (run phase 0 first)
│   │       ├── checked_path_templates
│   │       │   └── temp_dir/trim_scripts/{script_key}.ffscript
│   │       └── checked_runtime_templates
│   │           ├── is_trim_script_ready(...) is False
│   │           └── missing/invalid script means load_trim_script(...) cannot read a non-empty filter graph body
│   └── robustness
│       └── good; snippet skip is content-aware enough for the generated audio artifact, and Phase 1 also hard-requires one structurally valid Phase 0 trim script
├── phase_2_transcription
│   ├── skip_conditions
│   │   ├── transcript already exists and has non-whitespace UTF-8 content
│   │   │   ├── checked_path_templates
│   │   │   │   └── temp_dir/transcript/{basename}.txt
│   │   │   └── checked_runtime_templates
│   │   │       └── is_transcript_done(temp_dir, basename) -> path exists and read_text(...).strip() is non-empty
│   │   └── snippet missing or empty (run phase 1 first)
│   │       ├── checked_path_templates
│   │       │   └── temp_dir/snippet/{basename}.ogg
│   │       └── checked_runtime_templates
│   │           └── is_snippet_done(temp_dir, basename) is False
│   ├── robustness
│   │   └── good; invalid UTF-8 or whitespace-only transcripts are treated as not done
│   └── concerns
│       └── in horizontal local mode with Media Manager configured, Phase 2 sends the snippet for transient server analysis and writes both the transcript and the title
├── phase_3_title_generation
│   ├── skip_conditions
│   │   └── title file already exists
│   │       ├── checked_path_templates
│   │       │   └── temp_dir/title/{basename}.txt
│   │       └── checked_runtime_templates
│   │           └── is_title_done(temp_dir, basename) -> path.exists() only
│   ├── robustness
│   │   └── weak; skip logic is existence-only and does not validate non-empty title content
│   └── concerns
│       ├── there is no skip-time check for transcript readiness here; phase execution relies on upstream ordering and the title generator itself
│       └── an empty or whitespace-only existing title file still counts as done for skip purposes
├── original_upload
│   ├── runs_when
│   │   └── MEDIA_MANAGER_URL is set and --local-title-and-trim-only is not set; this is the only phase in that mode
│   ├── skip_conditions
│   │   ├── media manager disabled
│   │   │   ├── checked_path_templates
│   │   │   └── checked_runtime_templates
│   │   │       └── server_cache is None (the server original list did not load)
│   │   └── original already exists on server
│   │       ├── checked_path_templates
│   │       │   └── server:original/{basename}
│   │       └── checked_runtime_templates
│   │           └── server_cache.has_original("{basename}")
│   └── robustness
│       └── good; the server-side source ID is the stable key, and every later remote artifact links to it
├── phase_8_final_encode
│   ├── skip_conditions
│   │   ├── already completed
│   │   │   ├── checked_path_templates
│   │   │   │   └── temp_dir/completed/{basename}.txt
│   │   │   └── checked_runtime_templates
│   │   │       └── is_completed(temp_dir, basename) -> completion marker exists only
│   │   ├── transcript missing (run phase 2 first)
│   │   │   ├── checked_path_templates
│   │   │   │   └── temp_dir/transcript/{basename}.txt
│   │   │   └── checked_runtime_templates
│   │   │       └── is_transcript_done(temp_dir, basename)
│   │   ├── title missing (run phase 3 first)
│   │   │   ├── checked_path_templates
│   │   │   │   └── temp_dir/title/{basename}.txt
│   │   │   └── checked_runtime_templates
│   │   │       └── is_title_done(temp_dir, basename)
│   │   ├── title empty
│   │   │   ├── checked_path_templates
│   │   │   │   └── temp_dir/title/{basename}.txt
│   │   │   └── checked_runtime_templates
│   │   │       └── get_title_path(...).read_text(...).strip() == ""
│   │   └── trim script missing (run phase 0 first)
│   │       ├── checked_path_templates
│   │       │   └── temp_dir/trim_scripts/{script_key}.ffscript
│   │       └── checked_runtime_templates
│   │           ├── is_trim_script_ready(...) is False
│   │           └── missing/invalid script means load_trim_script(...) cannot read a non-empty filter graph body
│   ├── robustness
│   │   └── mixed; transcript/title emptiness is checked, but completion still trusts the marker file alone
│   └── concerns
│       ├── completed skip does not verify that the referenced MP4 exists in output_dir
│       ├── completed skip does not verify that completed.txt contains a non-empty output basename
│       ├── Phase 0 may still resolve to a stream-copy path at runtime, so a ready trim script does not guarantee Phase 8 will run FFmpeg; the copy path still writes the title into the container metadata
│       └── Phase 8 makes only the no-overlay video; it adds no overlay graph, no logo, and no subtitle track
├── modes
│   ├── media_manager_upload_only
│   │   └── when MEDIA_MANAGER_URL is set and --local-title-and-trim-only is not set, the client runs one Original Upload phase (skip: original already exists on server) and stops; the server worker makes the review audio and the no-overlay video
│   ├── horizontal_local_mode
│   │   └── --local-title-and-trim-only runs phases 0, 1, 2, 3, 8 and does no Media Manager upload
│   └── no_media_manager
│       └── without MEDIA_MANAGER_URL, the pipeline runs phases 0, 1, 2, 3, 8 on the PC and does no Media Manager upload
└── summary
    ├── phases_1_to_2
    │   └── content-aware and fairly robust
    ├── phase_3
    │   └── weakest local skip because title readiness is path existence only
    ├── original_upload
    │   └── solid; the server-side source ID is the stable key
    ├── phase_8
    │   └── brittle around completed.txt because completion is trusted without verifying the actual MP4
    └── media_manager_rule
        └── the client builds a server cache only for the Original Upload in media_manager_upload_only mode; other modes have no server cache
