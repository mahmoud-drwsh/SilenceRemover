# Issue tracker: GitHub

Issues and specifications live in this repository's GitHub Issues. Use the `gh` CLI from the repository root.

Create issues with `gh issue create`; read them with `gh issue view <number> --comments`; and apply labels with `gh issue edit <number> --add-label <label>`.

Pull requests are not a triage surface.

When an engineering skill says to publish to the issue tracker, create a GitHub issue.
